# Laboratório 1 — ambiente pronto

**Dia:** 1, abertura.

## Passos

1. Rodar o check:

```bash
curl -fsSL https://raw.githubusercontent.com/parisgroup-ai/imersao-ia-setup/main/scripts/check.sh | bash
```

2. Confirmar Superpowers, Design OS e Goal.
3. Abrir `~/founders-ai` no [[Orca]].
4. No Windows, confirmar terminal Ubuntu/WSL e projeto **fora** de `/mnt/c`.
5. Localizar `CLAUDE.md` e `AGENTS.md`. Usar `/init` só se as instruções faltarem. Ver [[AGENTS e CLAUDE]].
6. Reconhecer `pwd`, `ls`, `git status` e `git diff`. Ver [[Comandos do terminal]].

## Saída

Diagnóstico verde, ou bloqueio registrado com responsável.

## Recuperação

Reabra o Claude Code e repita o diagnóstico. Se continuar bloqueado, use a máquina preparada ou uma dupla — sem mudar a propriedade da entrega.
