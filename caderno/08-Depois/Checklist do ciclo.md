# Checklist do ciclo contexto + IA

Use a cada projeto novo. Uma volta de cada vez.

## Fase 1 — Contexto · capturar

- [ ] Descrevi o processo ou produto num briefing simples: o que faz, para quem, com quais regras.
- [ ] Mapeei o AS-IS → TO-BE com gargalos e métricas.
- [ ] Escrevi critérios de aceitação e decisões/exceções. Guardei no vault da empresa.

## Fase 2 — Geração · construir

- [ ] Abri o Claude na pasta do projeto e colei o contexto. Pedi primeiro o protótipo.
- [ ] Avancei em etapas pequenas: fachada, depois motor — uma de cada vez.
- [ ] Pedi “teste tudo antes de me mostrar” a cada passo. Salvei os prompts que funcionaram.

## Fase 3 — Teste e adoção

- [ ] Subi para o GitHub e, se autorizado, publiquei no Railway. Conferi o link.
- [ ] Conferi o que **não** deve ir para o ar — senhas, dados de clientes, chaves.
- [ ] Pedi: “liste o que neste projeto é sensível e não deveria ser publicado.”
- [ ] Defini o dono e mostrei para pessoas de confiança. Anotei o que melhorar na próxima volta.
