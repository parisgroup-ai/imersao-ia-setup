# Outro projeto, outra pasta

O método **não está preso** ao `~/founders-ai`. Uma pasta = um projeto. O ciclo viaja.

```text
~/founders-ai/          ← o da imersão (você continua nele)
~/meu-outro-produto/    ← pasta nova, mesmo ciclo
```

## Ritual de 5 linhas

1. Crie uma pasta nova (Finder ou `mkdir ~/nome-do-produto`).
2. `cd` nessa pasta + `claude`.
3. Diga: “Vamos repetir o ciclo: playbook → PRD com mapa de ondas → protótipo → onda 1 → no ar.”
4. Não misture dois produtos na mesma pasta.
5. Este caderno vai junto — é o manual, não o vault da empresa.

## O que não se repete

- Você não precisa da sala.
- Você não precisa de um mentor no ombro.
- Você não recomeça o curso ToStudy inteiro — só se o processo for novo e o playbook ainda não existir.
