# Caderno Founders

Base de conhecimento da Imersão **Founders AI**, da Paris Group.

Este caderno é o que você consulta durante os três dias e depois, sozinho. Ele não substitui o vault da sua empresa — aquele você monta no Dia 1. Este aqui é o manual vivo do método.

## Como abrir

No Orca ou em qualquer editor: abra `caderno/Comece aqui.md`.

No Obsidian (opcional): **Open folder as vault** → esta pasta `caderno/` → [[Comece aqui]].

Este caderno mora no repositório da imersão (`imersao-ia-setup/caderno/`). Atualize o repo e o caderno atualiza junto.

## O que tem aqui

- O método dos três dias, em linguagem simples
- Os 7 laboratórios, com prova no fim de cada um
- Os 6 prompts oficiais, prontos para colar (com **mapa de ondas**)
- Por que publicar, como continuar ESTE app, como abrir OUTRO projeto
- Modelos (playbook, QA, pasta do projeto, o-que-e-real)
- Guias para continuar sozinho
- Glossário, atalhos do Mac e comandos do terminal
- A apostila em PDF, em `Apostila/`

## O que este caderno não é

Não é o vault da sua empresa.  
Não traz dados de outros alunos, contratos, pagamentos ou materiais internos da equipe.
