# Claude e Claude Code

Nesta imersão, o parceiro de tecnologia é o Claude.

## O Claude

Inteligência artificial da Anthropic. Você conversa em português, descreve o que precisa, e ele entende, raciocina e produz: textos, análises, planos e código.

Analogia: um consultor brilhante disponível 24 horas, que lê tudo, não esquece detalhe e responde na hora.

Site: [claude.com](https://claude.com)

## O Claude Code

O Claude trabalhando **direto no seu computador**. Ele não fica só na conversa: cria arquivos, roda comandos, testa o que construiu e corrige os próprios erros.

Analogia: se o Claude é o consultor, o Claude Code é o funcionário que executa dentro da empresa.

Você chama pelo terminal, de preferência dentro do [[Orca]]:

```bash
claude --version
claude
```

Na primeira vez ele pede login no navegador. Confirme a pasta só se ela for sua.

## Por que o Claude, e não outra IA?

1. **O melhor do mundo para construir** — programação e agentes (IAs que executam tarefas de ponta a ponta).
2. **Executa a tarefa inteira** — em vez de só responder e devolver o trabalho para você terminar.
3. **Revisa o próprio trabalho** — testa e corrige antes de entregar.

A frase mais valiosa da imersão:

> Teste tudo antes de me mostrar o resultado.

## Modo automático

Por padrão, o Claude Code pede permissão antes de cada ação. No modo automático, ele executa a tarefa inteira sem parar a cada passo.

Dentro do Claude Code, **Shift + Tab** alterna os modos. O modo ligado aparece na barra de baixo.

## Quatro coisas que tiram o medo

1. Se há texto correndo ou um indicador girando, ele está trabalhando — espere.
2. Para interromper, aperte **Esc**.
3. Para sair e voltar ao terminal, digite `/exit` e Return.
4. Travou de verdade? Só então **Control + C**. Último recurso.

## Modelo e esforço

Modelos e níveis de esforço mudam tempo, custo e profundidade. Use a configuração da sala. Não escolha o maior por hábito.
