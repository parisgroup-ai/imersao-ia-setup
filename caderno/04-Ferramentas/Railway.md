# Railway

Onde o projeto vai para a internet.

Site: [railway.app](https://railway.app)

É o lugar em que o app sai do seu computador e ganha um endereço público.

Analogia: o imóvel comercial onde a loja abre as portas.

Por que isso importa (prova, uso, manutenção): [[Por que publicar]].

## Na imersão

Crie a conta antes do Dia 1, com a mesma conta do GitHub. O plano Hobby cobra um valor mensal pequeno e pede cartão. O trial serve para testar o deploy.

## Achar o link do produto

1. Entre em railway.app.
2. Abra o projeto → serviço principal → **Settings → Networking**.
3. Se já houver um endereço terminado em `.up.railway.app`, é o link.
4. Se não houver, clique em **Generate Domain**.

```text
railway.app → Sign in → seu projeto → serviço
→ Settings → Networking → link do produto
```

## Antes de gerar o link

Peça ao Claude: “liste o que neste projeto é sensível e não deveria ser publicado.”

Nunca publique senha, dado de cliente ou chave.
