# Terminal e Mac

O Terminal é só uma janela onde você conversa com o computador digitando, em vez de clicando. É por ali que você chama o Claude Code. Você vai usar pouquíssimos comandos.

Abra pelo Spotlight: **Command + espaço**, digite `Terminal` (ou abra o [[Orca]]) e aperte Return.

Os comandos deste caderno não quebram nada. A regra: use os comandos daqui, ou comandos que você entendeu. Se aparecer algo estranho, não continue — copie a mensagem e mostre ao Claude.

## Teclas

- **Command (⌘)** · **Shift (⇧)** · **Option / Alt (⌥)** · **Escape** · **Tab** · **Control**

## O essencial do dia a dia

| Atalho | O que faz |
|---|---|
| ⌘ C | Copiar |
| ⌘ V | Colar |
| ⌘ X | Recortar |
| ⌘ Z | Desfazer |
| ⌘ ⇧ Z | Refazer |
| ⌘ S | Salvar |

## Edição e busca

| Atalho | O que faz |
|---|---|
| ⌘ A | Selecionar tudo |
| ⌘ F | Buscar |
| ⌘ ⇧ V | Colar sem formatação |

## Tela e sistema

| Atalho | O que faz |
|---|---|
| ⌘ ⇧ 3 | Captura da tela inteira |
| ⌘ ⇧ 4 | Captura de uma área |
| ⌘ ⇧ 5 | Gravar a tela |
| ⌘ Tab | Alternar aplicativos |
| ⌘ espaço | Spotlight |

## Janelas

| Atalho | O que faz |
|---|---|
| ⌘ T | Nova aba |
| ⌘ W | Fechar aba |
| ⌘ Q | Fechar aplicativo |
| ⌘ ⌥ Esc | Forçar encerramento |

## Quatro coisas no Claude Code

1. Texto correndo = ele está trabalhando. Espere.
2. **Esc** interrompe.
3. `/exit` volta ao terminal.
4. **Control + C** é o último recurso.

Dica de quem já passou por isso: imprima [[Atalhos do Mac]] e deixe ao lado do teclado na primeira semana.
