# Guia 1 — começar um projeto novo do zero

Antes de tudo, confira se o Claude Code está instalado. Abra o terminal, digite `claude --version` e aperte Return. Apareceu um número? Pronto. `command not found`? Ainda não está instalado — veja [[Ambiente e instalacao]].

Nos blocos abaixo, o `$` é o sinal de que o terminal está esperando. **Não digite o `$`**, só o que vem depois.

## 1. Crie uma pasta para o projeto

No Mac: Finder → Documentos → Arquivo → Nova Pasta. Um projeto, uma pasta. Deixe a janela aberta.

## 2. Abra o Terminal dentro da pasta

Spotlight (`⌘ espaço`) → Terminal. Digite `cd` e um espaço. Arraste a pasta do Finder para a janela — ou escreva o nome. Return.

```bash
cd (arraste a pasta aqui)
```

## 3. Chame o Claude

```bash
claude
```

## 4. Descreva a ideia como descreveria a um sócio

O que o produto faz, para quem é, o que precisa ter. Sem termo técnico.

Exemplo:

> Quero criar um sistema de agendamento para a minha barbearia. Os clientes escolhem o horário pelo celular e eu vejo a agenda do dia. Comece pelo protótipo das telas.

## 5. Avance em etapas, igual na imersão

Primeiro o protótipo, depois as funcionalidades, depois GitHub e Railway.

Para o protótipo: “instale o Design OS e comece o protótipo das telas.”

Em cada etapa: “teste tudo antes de me mostrar.”

Ligue o modo automático com **Shift + Tab** se quiser que ele execute sem pedir permissão a cada passo. Ver [[Claude e Claude Code]].

Melhor ainda: use o ciclo [[O ciclo contexto + IA]] — contexto e playbook **antes** de pedir o protótipo.

Isso vale para **qualquer** pasta. O da imersão não é o único projeto da sua vida. [[Outro projeto, outra pasta]].
