# Guia 2 — manutenção de um projeto existente

Manutenção é voltar a um projeto que já existe para corrigir algo ou adicionar uma melhoria. O caminho é sempre o mesmo.

## 1. Encontre a pasta e abra o Claude

Spotlight → nome do projeto. Depois: `cd` com a pasta arrastada, Return, `claude`.

## 2. Peça um resumo antes de mexer

> Me explique o que este projeto faz e como está organizado, em linguagem simples.

## 3. Descreva o problema ou a melhoria

Seja específico.

> O botão de salvar não está funcionando. Investigue a causa e corrija.

> Quero adicionar um relatório mensal de vendas, com total por produto.

## 4. Teste, guarde e confira no ar

> Teste tudo o que você mudou e me mostre o resultado.

Depois:

> Faça commit e suba para o GitHub.

O Railway publica a nova versão sozinho, em poucos minutos — se o projeto já estiver ligado.

Uma melhoria incompleta não deve abrir três frentes novas. Primeiro decida: concluir, reduzir ou descartar.

O app da imersão é o primeiro caso: [[Este projeto continua]]. Peça a próxima **onda**, não “termina o sistema”.
