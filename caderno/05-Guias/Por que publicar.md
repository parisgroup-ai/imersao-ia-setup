# Por que publicar (GitHub + Railway)

Não é “para parecer técnico”. É para o produto existir sem o seu notebook.

## Sem o link × com o link

| Sem o link | Com o link |
|---|---|
| Só existe no seu computador | Qualquer pessoa abre no celular |
| Computador fechado = produto morto | Você desliga, o app continua |
| Cliente, sócio ou funcionário não testa | Você manda o URL e observa o uso |
| Melhoria some no disco | `git push` → o site atualiza sozinho |

## Três motivos, em voz de dono

1. **Prova.** O produto saiu da sua cabeça e ganhou endereço.
2. **Uso.** Sem URL, o [[Plano de 30 dias]] não tem usuário de verdade.
3. **Manutenção.** A onda 2 não exige “instala de novo no meu PC”. Você muda, sobe, o link é o mesmo.

## Dois papéis

- **GitHub** — o cartório. Guarda o histórico. Sem ele, o Railway não tem de onde puxar.
- **Railway** — a loja. É o endereço público. Analogia da apostila: o imóvel onde a loja abre as portas.

Push é a reposição de estoque.
