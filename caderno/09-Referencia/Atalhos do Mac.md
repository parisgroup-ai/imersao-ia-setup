# Atalhos do Mac

Imprima e deixe ao lado do teclado na primeira semana.

**⌘** Command · **⇧** Shift · **⌥** Option · **esc** Escape · **⌃** Control

## Essencial

| Atalho | Ação |
|---|---|
| ⌘ C | Copiar |
| ⌘ V | Colar |
| ⌘ X | Recortar |
| ⌘ Z | Desfazer |
| ⌘ ⇧ Z | Refazer |
| ⌘ S | Salvar |
| ⌘ A | Selecionar tudo |
| ⌘ F | Buscar |
| ⌘ ⇧ V | Colar sem formatação |

## Tela e sistema

| Atalho | Ação |
|---|---|
| ⌘ ⇧ 3 | Captura da tela inteira |
| ⌘ ⇧ 4 | Captura de uma área |
| ⌘ ⇧ 5 | Gravar a tela |
| ⌘ Tab | Alternar aplicativos |
| ⌘ espaço | Spotlight |

## Janelas

| Atalho | Ação |
|---|---|
| ⌘ T | Nova aba |
| ⌘ W | Fechar aba |
| ⌘ Q | Fechar aplicativo |
| ⌘ ⌥ Esc | Forçar encerramento |

## Claude Code

| Tecla | Ação |
|---|---|
| Esc | Interromper o que ele está fazendo |
| Shift + Tab | Alternar modo automático |
| `/exit` | Sair do Claude e voltar ao terminal |
| ⌃ C | Último recurso se travar de verdade |

Texto correndo na tela = ele está trabalhando. Espere.
